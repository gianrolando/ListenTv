# ListenTv 1.0.0 — stable

- Promote the working app to stable version 1.0.0.
- Replace Mediaset thumbnails with official 560-pixel color logos.
- Increase media/Android Auto artwork to 512x512, with lossless encoding.
- Remove the diagnostics menu from the phone interface.
- Add offline copyright, GPL license text and component credits.
- Produce a non-debug release APK and sign it locally with a dedicated key.

Repository visibility is private. This is a private stable delivery, not a public
GitHub or Play Store publication. Playback providers and package identity are
unchanged. Moving from a 0.x debug build requires a one-time uninstall because
the stable signing certificate is different.
